# Vendored platform provenance

The benchmark platform is a purpose-built derivative of
`roc-platform-template-zig` release 1.1.0, commit `7aee8ac`.

Only the platform sources, generated Roc ABI, Zig build support, license, and
prebuilt target inputs needed by Roc are retained in this flattened directory.
Local changes add monotonic timing and allocation telemetry around explicit
measurement markers.

The refcounted-list allocator also initializes the backing element count, as
generated by `src/glue/src/ZigGlue.roc` at Roc commit `a520eed` (2026-11-18).
The original vendored helper reserved this header but left it uninitialized.
A host test covers argument lists containing both inline and heap strings.

Linux host builds select musl, matching the platform's `x64musl`/`arm64musl`
linker inputs rather than the build machine's default GNU ABI. The output
directory follows the resolved target, including when cross-compiling.
