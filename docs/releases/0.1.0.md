# roc-graph-layout 0.1.0

The first release of deterministic graph layout for Roc: hierarchy, directed
flow, general graph and rule-based layout families that take node sizes and
return node positions, edge routes and bounds.

Add the package to an application header:

```roc
app [main!] {
	layout: "{package-url}",
}
```

## Changes

- Versioned API reference and a documentation site
- Routing quality improvements
- Release bundle and documentation fixes
