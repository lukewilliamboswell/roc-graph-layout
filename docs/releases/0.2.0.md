# roc-graph-layout 0.2.0

This release moves the package to current Roc nightlies. Release 0.1.0 does
not compile with them, so upgrade to 0.2.0 together with your compiler.

```roc
app [main!] {
	layout: "{package-url}",
}
```

## Breaking changes

- The package no longer pins a Roc compiler in its header. It is built and
  tested with the latest nightly; the Compilers section below names the one
  this release was tested with. Earlier nightlies, before nominal types needed
  to opt in to equality, are not supported.
- Release 0.1.0 could not be compared with this one by `roc bump`, because it
  no longer compiles; treat every module as changed.

## Changes

- `Route.Problem` and `Layered.Problem` support `==`, so validation results
  can be compared directly. Prepared values remain opaque and do not.
- Each release now attaches `roc-graph-layout-examples-0.2.0.zip`: the
  examples as they were at release, depending on this release's bundle, with
  their expected output. A daily job checks them against the latest nightly.
- The API reference of each release is attached as
  `roc-graph-layout-docs-<version>.zip` and published on the documentation
  site beside every earlier release.
- The interactive playground is not on the site in this release; it returns
  with a roc-signals release that supports current nightlies.
