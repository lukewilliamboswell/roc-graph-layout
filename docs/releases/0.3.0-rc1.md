# roc-graph-layout 0.3.0-rc1

A release candidate of 0.3.0, for trying the new Mermaid package and the
faster layered layout before the final release. It publishes two packages
built from the same source: the layout package, and a Mermaid package that
depends on this release's layout package.

```roc
app [main!] {
	layout: "{package-url}",
	mermaid: "{mermaid-url}",
}
```

Declare only the packages you use: an application that only draws Mermaid
text needs `mermaid` alone.

## Mermaid package

`Mermaid.svg` turns Mermaid flowchart text (`flowchart` or `graph`) into a
standalone SVG document in one call:

```roc
match Mermaid.svg("flowchart LR\n  A[Start] --> B{Choice}\n") {
	Ok(svg) => Path.write_utf8!(Path.utf8("chart.svg"), svg)
	Err(problems) => Err(MermaidProblems(problems))
}
```

- It reads text as Mermaid 12 does, measures labels with the metrics of the
  Inter typeface and lays the chart out as Mermaid's ELK layout does. Show the
  SVG where Inter is available, for example as a web font, for labels to fit
  their boxes exactly.
- `Mermaid.draw` returns the same picture as outlines and text lines for any
  vector renderer, such as a PDF writer, and `Drawing` describes it.
  `Flowchart.parse` gives the diagram itself: nodes, edges and groups.
- Text Mermaid accepts but this package does not interpret yet, such as
  `click` handlers or front matter, is reported as a problem rather than
  drawn approximately. Diagrams other than flowcharts are not supported.
- The package carries Inter's font metrics under the SIL Open Font License
  1.1; `Mermaid.font_licence` is its text, to include with anything that
  redistributes them.

## Breaking changes

- `Layered.Settings.routing` is now `[Straight, Orthogonal(Route.Settings)]`,
  the choice `Compound` already offers, so callers can skip routing.
- `Compound`'s layered `edge_weights` and `min_spans` now name edges by their
  index in the whole input, as `non_ranking_edges` already did, rather than
  by their index among a group's own edges.
- `roc bump` cannot read the public API of 0.2.0, so this release was not
  compared with it automatically; the breaking change above was found by
  hand.

## Changes

- Layered layout scales about linearly with graph size; default results are
  unchanged.
- Layered results add `layer_points`, one point per crossed layer for each
  edge, and `Layered.Settings` adds `ordering`.
- Compound layout gives edge labels room inside layered groups.
