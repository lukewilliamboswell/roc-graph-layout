# roc-graph-layout 0.3.0-rc3

This candidate fixes the package URL collision in 0.3.0-rc2. Both packages
now have distinct versioned identities and can be used together:

- Layout package: `{package-url}`
- Mermaid package: `{mermaid-url}`

Use this candidate instead of rc2 for Mermaid. Its archives are named
`layout-<hash>.tar.zst` and `mermaid-<hash>.tar.zst`; the prefixes distinguish
the packages in Roc's version resolver. The Mermaid archive declares this
release's matching layout URL. Existing rc2 assets and its tag are unchanged.

## Included functionality

This candidate retains rc2's reusable grouped directed layout and support for
Mermaid flowcharts, sequence diagrams, entity relationship diagrams, class
diagrams, and state diagrams. Defaults follow pinned Mermaid 12.2.0; custom
styling is opt-in. These families do not implement the entire Mermaid grammar.
The canonical oracle runs in pinned Chrome on Linux x64 and uses semantic,
geometry, canvas, and image gates; this is not a claim of universal pixel parity.

The proposed 0.3.0 API includes rc1's breaking changes to
`Layered.Settings.routing`, compound layered edge indexing, and orthogonal
routing output. The packaging fix does not change the layout or Mermaid APIs.

## Validation

Release tests now preserve versions in loopback URLs and check a consumer
importing both packages from an empty cache. A negative control removes the
prefixes and must reproduce the conflicting-package error. The new check
rejects the exact published rc2 archives, and the corrected archives pass it.
All 17 archived native examples build and run against the corrected packages.
The full repository checks and independent Mermaid oracle remain release gates.

Automatic API comparison with 0.2.0 remains unavailable: current `roc bump`
cannot extract that release's public API because it references the unexposed
`Constrained.ConstrainedPrepared` type. The release uses the explicit workflow
exception; no successful automatic compatibility comparison is claimed.

The node-editor service check, native smoke run, and browser job remain
explicitly skipped with TODOs for
[Roc issue #12677](https://github.com/roc-lang/roc/issues/12677) and the remaining
Datastar inference errors. These exclusions do not disable package tests,
runnable examples, or the Mermaid oracle. `RUN_NODE_EDITOR_CHECKS=1` retries
the service and smoke checks locally; the repository variable enables all
node-editor checks in CI.
