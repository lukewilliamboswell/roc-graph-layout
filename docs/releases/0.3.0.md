# roc-graph-layout 0.3.0

This release publishes two packages with distinct versioned identities:

- Layout package: `{package-url}`
- Mermaid package: `{mermaid-url}`

The Mermaid package imports the matching layout bundle. Applications that only
draw Mermaid diagrams can declare Mermaid alone. The packages and maintained
examples support Roc `nightly-2026-11-07-ad3a5d2`; CLI applications use basic-cli
0.27.0. The independent repository tooling compiler remains unchanged.

## Breaking changes

- `Layered.Settings.routing` is `[Straight, Orthogonal(Route.Settings)]`.
- Compound layered `edge_weights` and `min_spans` use whole-input edge indices.
- Cleaner orthogonal routing can produce routes different from 0.2.0.

Version 0.3.0 crosses the breaking-version boundary from 0.2.0. The release
validator verifies that boundary and the previous release's bundle identity,
so no automatic public API comparison is required. The compiler cannot extract
0.2.0's API because it references the unexposed
`Constrained.ConstrainedPrepared` type; this release does not claim a successful
API comparison. A version within the same boundary still requires `roc bump`.
The old unrestricted API-comparison override has been removed.

## Mermaid and grouped layout

`Mermaid.svg` and `Mermaid.draw` support flowcharts, sequence diagrams, entity
relationship diagrams, class diagrams and state diagrams. Each family exposes
its parser and source-ordered model. Unsupported syntax and invalid numeric
theme options return problems. The supported grammar is a subset of Mermaid.
Defaults follow pinned Mermaid 12.2.0; custom styling is opt-in. SVG text needs
Inter and suitable fallback fonts to match the measured bounds.

`Layered.prepare_grouped` and `Layered.layout_grouped` support recursive groups,
measured node and edge-label sizes, node or group endpoints, and explicit
direction. Results preserve source indexing and include group boxes, routes,
endpoint attachments, layers and edges routed against the flow. Successfully
prepared layout remains total. The layout package needs no renderer or font.

## Release evidence

The candidate tests exercise both bundle namespaces together from an empty
cache, retain the negative package-identity control, and compare all 17 archived
native examples with their recorded outputs. The full repository checks,
Linux/macOS native builds, independent Mermaid oracle, documentation build and
archive checks remain release gates. Oracle evidence covers its declared cases
and environment, not universal pixel parity.

The node-editor service, native smoke and browser checks remain explicitly
excluded from this release's evidence. Its older web-platform/configuration
integration still needs repair. These exclusions do not remove any of the 17
runnable archived examples or their assertions. `RUN_NODE_EDITOR_CHECKS=1`
retries the service checks and the repository variable enables browser CI.
