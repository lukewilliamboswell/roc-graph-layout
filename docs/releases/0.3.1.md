# roc-graph-layout 0.3.1

The examples archive explicitly launches each application from the suite root,
matching its documented root-relative input and output paths. Its `spec.json`
declares an archived Python 3 launcher using the shared runner's existing runtime
argv contract. Arguments, standard input, standard output, standard error and
exit status pass through unchanged.

The candidate checks retain the original root harness and additionally run every
archived application from its own directory with cold checks and native builds.
The layout and Mermaid source and their public API are unchanged. A later-patch
content proof compares freshly built bundles with the verified immutable 0.3.0
assets: exact layout bytes and exact Mermaid members with only its declared URL
rebinding to that identical layout. Other package changes still require the strict
layout API comparison; admission and freshness failures stop publication.
